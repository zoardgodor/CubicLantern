The Linux version is a .tar.gz package built and tested on Linux Mint. On other distributions, you may need to build the application yourself. View Linux downloads on GitHub Releases.

A server that stays at home

Everything you need to turn an everyday PC into a friendly Minecraft server.

Host on your own PC

No rented hosting required. Keep your worlds and files at home, and connect players through a tunnel without opening router ports.

Have an old potato PC? No problem

PumpkinMC is a lightweight Minecraft server implementation, and it is available in CubicLantern alongside Java.

Choose your connection

Use Playit for a stable address, or Pinggy for a quick, simple connection. Java, Bedrock and HTTP tunnels can be configured to fit your server.
