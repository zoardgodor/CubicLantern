CubicLantern - build a Windows executable from the split Python files with PyInstaller

WINDOWS
========

Open PowerShell in the project folder.

Create and activate a virtual environment:

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1

If PowerShell blocks activation, run PowerShell as the current user and then try again:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Install the dependencies:

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Build the windowed executable:

python -m PyInstaller --noconfirm --clean --onedir --windowed --hidden-import=PySide6.QtCore --hidden-import=PySide6.QtGui --hidden-import=PySide6.QtWidgets --hidden-import=psutil --hidden-import=winpty --hidden-import=uuid --hidden-import=tarfile --hidden-import=shlex --hidden-import=signal --hidden-import=threading --hidden-import=secrets --hidden-import=urllib.request --hidden-import=urllib.error --hidden-import=urllib.parse --add-data "reszek;reszek" --add-data "icon-CL-icon-pack\icon-CL.ico;." --icon=icon-CL-icon-pack\icon-CL.ico --name CubicLantern main.py


For a console version useful for debugging, use this instead:

python -m PyInstaller --noconfirm --clean --onedir --console --hidden-import=PySide6.QtCore --hidden-import=PySide6.QtGui --hidden-import=PySide6.QtWidgets --hidden-import=psutil --hidden-import=winpty --hidden-import=uuid --hidden-import=tarfile --hidden-import=shlex --hidden-import=signal --hidden-import=threading --hidden-import=secrets --hidden-import=urllib.request --hidden-import=urllib.error --hidden-import=urllib.parse --add-data "reszek;reszek" --add-data "icon-CL-icon-pack\icon-CL.ico;." --icon=icon-CL-icon-pack\icon-CL.ico --name CubicLantern-Debug main.py

NOTES
=====

The generated executable is placed in the dist folder. The build folder and the .spec file can be removed after a successful build if they are not needed.

Pinggy is not bundled with CubicLantern. Download the official Windows client from https://pinggy.io/cli/ and import it in the application.

Playit is downloaded by the application from the official playit-cloud/playit-agent release source when it is first started.
